# 语种表与颜色分工

## 颜色分工规则

原设计常见「关键词用亮色、其余奶白」，例如 `My Teacher / My White Knight` 是「My 奶白 + Teacher 亮红」。
翻译成别的语言时按语义给，不要机械照搬"第一个词奶白"。

- 两段式：奶白部分在前、彩色部分在后（按该语言的正常语序）
- 若第一行整个就是一个关键词（日语 メンター、韩语 멘토、印尼语 Mentorku），则**整行亮红**
- 第二种行通常一律整行奶白
- 换一张风格不同的海报时，这条"哪个词是亮色"的规则要按新设计的实际配色重新判断
- 同一句标题拆成几行时，按**语义层级**拆：动词/关键词 → 大字/花体；宾语/限定语 → 小字/衬线

对应 prompt 里 `{spec1}` 的写法见 `prompts.md`。
