# 多语言封面换字（保留设计，只换标题文字）

输入：一张封面/海报 + 一串多语种译文。输出：同一张封面 × N 个语种，
人物、背景、平台徽章、字体风格、标题位置全部保持，只把标题换成目标语言。

## 铁律（必须遵守）

1. **每一步的产物都要 `render_media` 给用户看**，用户确认后再走下一步。不许一口气跑完再汇报。
2. **去向由用户决定**：本流程**不包含任何发送动作**，发到哪里、发不发给谁，用户说了才做。
3. **标题区域坐标只能自己看图读**，禁止用脚本/颜色阈值去计算或推断文字区域。
4. `view_image` 是核心工具：有没有字、字在哪、字形对不对、像不像，全靠自己看。
5. 对外说明文字不要出现技术词（不提模型名、不说"抠图/键控/base64"），只说"设计、人物、字体风格保持原样，只换了标题"。
6. **脚本就在本技能里**：`<skill>/scripts/cover_swap.py`。要用就直接跑它，
   **不要在工作区另写一份临时脚本**（工作区会被清理，散落的脚本下次就找不到了）。

## 流程总览

```
第0步  我自己看图，读出标题区域坐标（用 grid 画刻度辅助，不用任何脚本去识别）
第1步  整图送 edit 模型，把标题文字抹掉 → 无字底图
第2步  在"与字色相反的纯色底"上，让模型写出目标语言的标题（含装饰件）
第3步  本地抠出文字 → 按第0步自己读的坐标摆好 → 补柔光/投影 → 贴到无字底图上
第4步  批量出 N 个语种 + 中文标签总表 + zip
```

## 第 0 步：自己看图，读标题区域

- `view_image` 看原图，确认：标题有几行、每行文字、哪个词是彩色、字体风格、标题压不压人物、头发从哪开始。
- 需要更精确时，画一张**刻度尺**给自己看——它**只画线，不做任何识别**，坐标由我自己读：
  ```bash
  /d/mafagent/python/python.exe <skill>/scripts/cover_swap.py grid \
      --image 原图.jpg --out grid.png --step 50 --scale 1.0 --crop 0.6,1.0
  ```
  规则：刻度图**每条线都有自己的数字，不跳号**；数字**竖排**；刻度画在图外黑边里、不遮画面。
  `--scale` 放大幅度、`--step` 线距。**画完必须 `view_image` 确认读数清晰**。
- 读数时把**每一条**文字元素都量出来（第 1 行、第 2 行、装饰件、徽章），后面 paste 的 `--box` 要用。
- ⚠️ **不许用颜色阈值/脚本去"找"文字区域**。实测同一套阈值：星空图框住整条天空、油画人像框到额头高光、
  浅底截图框住整片背景；而且它**判断不了"这张图到底有没有标题"**——眼睛可以。

## 第 1 步：抹掉原文（整图送，不裁切）

- **拿完整原图**送 `openai-images`（gpt-image）`edit`：把标题各行、装饰拖尾、投影、发光全部抹掉，
  背景自然补齐，输出里不许有任何文字。
- prompt 见 `references/prompts.md` 的「抹字」。
- **不要"裁出文字区域→抹掉→再贴回"**：裁切会让上下部分完全对不上，这条路行不通。
- `size` 必须是 16 的倍数或 auto，且**别小于约 50 万像素**（`1024x1520`、`1536x816`、`1024x1360` 可用）。
- 产物 = **无字底图**。`render_media` 给用户看，确认后再往下。
- 若被安全审核拦（`safety_violations=[sexual]`）→ 见下面「安全审核退路」。

## 第 2 步：生成新语种标题（纯色底，颜色与字色相反）

- 输入参考图：**原图的标题裁片**（只裁文字区域，别把敏感部位裁进去）——用来传递字体风格与配色分工。
- **底色按字色选反差色**：

  | 标题字色 | 该用的底色 |
  |---|---|
  | 奶白 + 亮红 | 蓝 (0,0,255) |
  | 蓝色字 | 橙 / 黄 |
  | 黑色 / 深色字 | 白 / 亮青 |
  原则：底色要和**所有**字色都拉开距离，键控才干净。蓝底的好处是 despill 能顺手压掉蓝色边缘。

- prompt 见 `references/prompts.md` 的「花字」，`size` 用与标题块**同比例**的尺寸（如 `1536x896`、`1536x688`）。
- 颜色分工按语义给（原设计是「关键词亮色、其余奶白」，见 `references/languages.md`）。
- **字号比例也要写进 prompt**：第二行/副标题在原设计里往往又大又宽，不写清楚模型会给成"小字幕"。
  实测补一句「line 2 about 85-90% of the frame width, caps ~35-40% of line 1's height」就能对上。
- 非拉丁文字（日/韩/泰/阿拉伯…）**必须**再喂一张"用系统字体排出来的正确字形"参考图，
  否则字形是编的。副作用：模型会往参考的笔画靠，那一行容易看起来像印刷体——可接受，但要跟用户说明。
- 产物 `render_media` 给用户看。

## 第 3 步：抠图 + 贴回（坐标全靠人读，脚本不做识别）

```bash
# 1) 先在"无字底图"上画刻度线，自己读出新标题该占的区域 --box x0,y0,x1,y1（底图像素坐标）
/d/mafagent/python/python.exe <skill>/scripts/cover_swap.py grid \
    --image 无字底图.png --out grid_base.png --step 50 --scale 0.55 --crop 0,0.42
# 2) 抠出纯色底上的字（逐像素颜色运算）
/d/mafagent/python/python.exe <skill>/scripts/cover_swap.py key --plate 纯色底图.png --out keyed.png
# 3) 按自己读出来的 box 贴回
/d/mafagent/python/python.exe <skill>/scripts/cover_swap.py paste \
    --text keyed.png --base 无字底图.png --out 成品.png --box 140,80,1000,540
```

- `--box` 是**人看着刻度线读出来的**目标区域；脚本只按它的宽度做**等比缩放**、左对齐、垂直居中，
  **不做任何文字识别**。摆位不满意就改 `--box`，或调 `--halign/--valign`。
- ⚠️ **box 不要超出画布**：花字两端的装饰件（拳套、尾巴、飘带）就是 alpha 包围盒的边缘，
  box 一旦宽过画布，端部装饰就被裁掉——用户一眼看出来（「拳套太靠边/被切了」）。
  做法：先量**原图**里同样端部装饰的落点，再按这个范围给 box，两边各留 2~3%。
- **柔光**：原设计带发光的，生成时让模型**不要画光**（crisp edges），贴回时用
  `--glow-op 0.5 --glow-px 9 --glow-color 200,235,250` 补——比让模型画光更好抠、强度可调。
- **投影**：默认不加（`--shadow-op 0`）。原设计有投影再用 `--shadow-color/-dx/-dy/-blur/-op`，
  不要用 `--fit both`，那会拉伸字形。
- 严格禁止用 numpy/cv 的颜色阈值、形态学、连通块去"找文字"。
- 抠图结果必须 `render_media` 给人看：有没有底色描边、笔画有没有变薄。

## 第 4 步：批量与交付

- 多语种：先并发跑第 2 步（一个语种一次调用，4~5 并发），再循环第 3 步。
- **成品尺寸 = 原图尺寸**（用户通常明确要求）。底图/花字都在大尺寸上做，最后 `cv2.resize` 回原尺寸。
- 成品命名 `<目录>/<语种码>.png`，拼中文标签总表：
  ```bash
  ... cover_swap.py sheet --dir out --out 总表.png --labels "nl=荷兰语,fr=法语,..."
  ```
  逐张 `view_image` 抽查，然后 zip 打包（`zipfile`，内含 N 张 + 总表）。
- **去向与发送由用户决定**，本流程不做任何发送。

## 装饰部件：必须跟花字走，不能留在底图（实测踩过）

很多封面标题自带**装饰部件**：爱心、金冠、猫耳、猫爪印、蝴蝶结+铃铛、猫尾巴、拳套、飘带拖尾、唇印。
用户明确要求过「这些元素不能丢，而且要和文字在一起」——**留在底图上会被新文字盖住**，是错的。

正确分工：

| 层 | 内容 |
|---|---|
| 底图（第 1 步抹掉） | 标题文字 **+ 全部装饰部件**，一个不留 |
| 花字层（第 2 步生成、第 3 步贴回） | 目标语言文字 **+ 同样的全部装饰部件** |

> **先问用户有没有现成的干净底图**（美术侧往往有高清、无字、甚至无装饰的底图）。
> 有就直接拿它当底图，第 1 步整段省掉；只让模型去掉底图上残留的装饰件即可（prompt 要点名：
> 只删粉色爱心/红色拳套/尾巴+蝴蝶结铃铛这类装饰，**场景里的大件（黑拳套、猫爪手套、猫耳发箍）必须保留**）。
> 实测 `seedream`、`wan2.70-image-pro` 干这件事都很干净；seedream 偶尔右下角带自家水印，用前放大看一眼。
> 例外：用户说「唇印就这样吧、文字位置迁就它」时，就留在底图、把花字整体挪开（上移/左移十几像素）即可。

- 第 1 步 prompt 要逐个点名装饰件（crown / hearts / cat ears / paw print / bow with bell / tail /
  boxing gloves / swash strokes / lipstick kiss），说清「填平、自然融合」。
- 第 2 步 prompt 加一段装饰描述句（位置、颜色照原设计说），并**保留同一张含装饰的原图作风格参考**。
- 注意区分**场景里本来就有的同类元素**（人物头上真戴着猫耳发箍、手上真戴猫爪手套）
  与**标题的装饰件**：前者留在底图里，后者跟花字走；两者都要有，别把人物身上的删掉。

## 安全审核退路（safety_violations=[sexual]）

成人向封面把整块标题（含装饰）抹掉时，模型会去"脑补"被标题遮住的部位 → 输出被判 sexual，反复重试也没用。
实测有效顺序：

1. 换措辞、点名要抹的元素，重试几次（有时能过）。
2. **先用成功过的那次结果当输入**再抹一次（画面已经干净，二次编辑更容易过审）。
3. **换别的图像模型做去字**：`wan2.70-image-pro`（size 写 `1024*1530` 这种 `宽*高`，配 `prompt_extend: false`）
   和 `seedream`（即梦/豆包，size 用 `1584x2352` 这类同比例大图）。这两个对"删掉文字与装饰、别的一律不动"
   很听话，**构图保持得比 gpt 重绘版好**；seedream 偶尔右下角带水印，wan 不带。
4. **花字生成时的 404 `model not found`**：上游偶尔把 `openai-images` 路由到不支持的节点（PPIO），
   重试即可，脚本里要写成 3~4 次重试；13 个语种里通常 2~4 个需要重试。
5. **平台徽章**（EXCLUSIVE 之类）常被顺手抹掉，要补回原位。**优先问用户有没有现成的 logo 素材**
   （通常能给出干净的透明 PNG），没有再从原图裁该区域放大贴回。摆放：按原徽章中心点摆、宽度对齐原徽章宽度，
   **先贴 logo 再贴花字**（原设计里花字压在徽章上沿）。

## 通用性：哪些是流程，哪些每张图都要重做

**换任何海报都一样（直接复用）**：三步流程本身、抹字/花字 prompt 的结构、抠图算法与参数区间、
贴回的对齐逻辑、柔光/投影参数、总表脚本。

**每张图必须重做或重调的**：

| 项 | 怎么做 |
|---|---|
| 标题框坐标 | 自己看图读（第 0 步），禁止脚本推断 |
| 有没有标题 / 有几行 | 眼睛看；阈值法判断不了 |
| 语种分行拆法 | 按该语言语序拆成与原设计同层级的几段（动词放花体、宾语放衬线） |
| 底色选什么颜色 | 按字色选反差色 |
| 字号比例 | 把原设计的相对大小写进 prompt（副行往往要大而宽） |
| 柔光/投影 | 换设计就要调 `--glow-*` / `--shadow-*` |
| 非拉丁文字 | 每次都要做字形参考图 |

## 已知坑清单

| 坑 | 现象 | 处理 |
|---|---|---|
| 在工作区另写脚本 | 工作区被清理后脚本没了，只能重写 | 一律用 `<skill>/scripts/cover_swap.py` |
| 裁文字区域再贴回 | 上下完全对不上、留残影 | 走整图抹字，别裁 |
| 用 numpy/cv 找文字 | 星空、人像、浅底图全误检，还判断不了"有没有字" | 一律人看图读坐标（可用 grid 画刻度辅助） |
| 底色固定用蓝 | 字本身是蓝的就抠不出来 | 按字色选反差色 |
| `cv2.copyTo` 参数顺序 | 贴回后成品与原图完全一样（差异 0） | 用 numpy 混合 |
| 底色 spill | 字周围一圈底色描边 | 收 1px + 去溢色 + 反预乘 |
| alpha 阈值过高 | 字变薄、变平、倒角丢失 | 阈值区间放到 30/110 |
| box 宽过画布 | 端部装饰被裁、用户说"拳套太靠边" | box 按原图端部装饰落点给，两边留 2~3% |
| 副标题生成成小字幕 | 与原设计比例差很多 | prompt 里写死相对宽度/字高 |
| 模型画了发光 | 抠出来一圈毛边 | 生成时要求 no glow，贴回时用 `--glow-op` 补 |
| 非拉丁文字乱码 | 泰文像鬼画符、韩文变拉丁 | 加字形参考图（第 2 步） |
| 自己觉得"没问题" | 用户说"明显不对" | 每步都 render_media 给用户看，让他判断 |

## 附：环境

- 网关：`POST http://127.0.0.1:80/api/v1/media/invoke`，模型 `openai-images`（= gpt-image），
  operation `edit`。参考图传 `{"base64":...,"mime_type":"image/png"}`，最多 16 张；
  返回 `data.paths` 直接 `render_media`。去字备选：`wan2.70-image-pro`、`seedream`（operation `generate`）。
- 图像处理用 **`D:/mafagent/python/python.exe`**（有 numpy 2.3 / cv2 5.0）；默认 `python` 没有 numpy/cv2。
- 附属文件：`scripts/cover_swap.py`（grid / key / paste / sheet）、
  `references/prompts.md`（prompt 原文）、`references/languages.md`（语种与颜色分工表）。
